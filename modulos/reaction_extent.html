Grado de avance de reacción

Explora la coordenada ξ para conectar estequiometría, moles finales, conversión y factibilidad física.

Calculadora

Usa ν negativo para reactantes y positivo para productos. Ejemplo: A + B → C se escribe νA=-1, νB=-1, νC=+1.

Resultados

Aprendizaje

El grado de avance de reacción ξ mide cuánto ha progresado una reacción escrita con una estequiometría fija. Para una sola reacción independiente, un solo número ξ actualiza todas las especies.

nᵢ = nᵢ,0 + νᵢ ξ

Signo de νᵢ

Reactantes tienen νᵢ negativo porque se consumen. Productos tienen νᵢ positivo porque se forman. Si ξ aumenta, los reactantes bajan y los productos suben.

Conversión

Para un reactante A, X_A = moles consumidos / moles iniciales. Si ν_A < 0, entonces X_A = -ν_A ξ / n_A,0.

Por qué importa

ξ conecta balances molares, composición, conversión, equilibrio y reactores. Más adelante, el equilibrio químico se puede plantear buscando el ξ que minimiza Gibbs o satisface K.

Errores comunes

  • Usar coeficientes positivos para reactantes.
  • Olvidar que ξ tiene unidades de mol de reacción.
  • Elegir un ξ que vuelve negativos los moles finales.
  • Confundir conversión de un reactante con avance de reacción.

Exploración

Elige un preset, mueve ξ y observa cómo cambian moles y fracciones molares.

Datos / Soporte técnico

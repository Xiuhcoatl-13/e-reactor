Conducción transitoria / Biot-Fourier

Criterio Bi, número Fo y temperatura transitoria con capacitancia concentrada.

Placa plana: usa Lc = V/A_s. Para una pared plana de espesor 2L con ambas caras expuestas, Lc ≈ L.

Qué es conducción transitoria

Hay conducción transitoria cuando la temperatura del sólido cambia con el tiempo. A diferencia del estado estacionario, la energía interna del sólido también importa.

Biot y Fourier

  • Bi = hLc/k: compara resistencia conductiva interna contra resistencia convectiva superficial.
  • Fo = αt/Lc²: tiempo adimensional; mide cuánto ha avanzado la difusión térmica dentro del sólido.

Capacitancia concentrada

Si Bi < 0.1, los gradientes internos son pequeños y el sólido puede aproximarse con una temperatura uniforme que cambia exponencialmente.

θ/θi = (T - T∞)/(Ti - T∞) = exp(-Bi·Fo)

Errores comunes

  • Usar Bi < 0.1 como garantía absoluta sin revisar geometría o propiedades.
  • Usar k del fluido; Bi usa k del sólido.
  • Confundir Lc con espesor total. Para muchas formas Lc = V/A_s.
  • Aplicar el modelo concentrado con Bi grande, donde hay gradientes internos importantes.
Conexión: usa h desde Convección de calor y revisa Bi/Fo también en Números adimensionales v2.0.

Criterio de Biot

Bi < 0.1Modelo de capacitancia concentrada usualmente aceptable.
0.1 ≤ Bi ≤ 1Gradientes internos pueden importar; usar solución transitoria 1D o cartas de Heisler.
Bi > 1Resistencia interna dominante; el modelo uniforme no es apropiado.

Fourier

Fo = αt/Lc². Fo pequeño indica tiempos cortos o difusión lenta; Fo grande indica que el sólido avanzó hacia el equilibrio térmico.

Cuándo pasar a un modelo avanzado

  • Bi ≥ 0.1.
  • Temperatura superficial no uniforme.
  • Propiedades cambian fuertemente con T.
  • Conducción multidimensional o generación interna de calor.
